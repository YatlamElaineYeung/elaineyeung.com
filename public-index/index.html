Cloudflare Edge

Worker + static assets · DNS · TLS · redirects · contact form

  • Agent with real tools: the agent read source files, generated HTML/CSS/JS, upgraded the Node.js runtime, and drove the Wrangler CLI and Cloudflare API on its own.
  • Human-in-the-loop guardrails: publishing to the public internet was blocked by a permission gate until I explicitly approved it.
  • Self-correcting: when Cloudflare's legacy Pages deploy path failed, the agent diagnosed the error and migrated the project to Workers static assets.
  • Private contact form: a serverless form (Workers, D1, KV) protected by Cloudflare edge rules, a Turnstile bot check, matching client and server validation, private link screening, and rate limits stored as salted hashes, so no email address or phone number is ever published.
  • Edge routing: a Cloudflare Worker sends all http:// and www traffic to https://elaineyeung.com with 301 redirects.
  • DNS migration: moved the domain from Namecheap to Cloudflare nameservers, cleaned up parking records, and attached custom domains with automatic TLS.
  • Verified end to end: every URL variant was tested with automated checks after each deploy.
  • Reliable delivery: every message is saved before it's sent, retried automatically, confirmed by signed delivery webhooks, and flagged by a daily alert if it gets stuck. Email is authenticated with SPF, DKIM, and a strict DMARC policy, and the form's logic is covered by unit tests.

Python · Privacy by Design

Contact QR Code Generator

Personal tool · 2026

View Code

A Python tool that turns my contact details into a QR code. One scan with a phone camera saves me as a contact, with no app or internet connection needed, which makes swapping details at networking events fast and typo-free.

  • Standards-based: builds a vCard 3.0 contact card with spec-compliant escaping, CRLF line endings, and international phone format, so it imports cleanly on iPhone and Android.
  • Privacy by design: personal details live in a gitignored file and the generated codes are excluded too, so the public repository holds only placeholder data.
  • Data-driven trade-offs: chose a self-contained QR code over a hosted link so it works offline and keeps details private.
  • Verified: decoded the generated image to confirm it matches the source byte for byte, then tested it on a real phone.
